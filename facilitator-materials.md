# Facilitator materials checklist

What to have ready for each of the two deliveries. Pair with
[contingency-plan.md](contingency-plan.md) and the prep checklist at the end of
[facilitator-guide.md](facilitator-guide.md).

## Both modalities

**Content**
- [ ] [facilitator-guide.md](facilitator-guide.md) open on a second screen or printed
- [ ] [slides/slide-outline.md](slides/slide-outline.md) built into a deck, or presented as-is
- [ ] [participant-workbook.md](participant-workbook.md) link ready to paste
- [ ] [exercises/](exercises/) and [exercises/solutions/](exercises/solutions/) open in tabs
- [ ] [governance/pr-checklist.md](governance/pr-checklist.md) open for Session 2
- [ ] [contingency-plan.md](contingency-plan.md) open

**Pre-staged assets**
- [ ] Screenshot of the weak starter prompt output from your rehearsal
- [ ] Your own fork of the repository with one example pull request already open
- [ ] Issues enabled in your fork, or a pre-opened issue editor; new forks may have Issues off
- [ ] A copied set of chat messages: repository link, workbook link, four activity briefs, the
      break return time, the knowledge-check questions
- [ ] A visible timer

**Accounts and access**
- [ ] Signed in to GitHub in the browser you will present from
- [ ] Microsoft Copilot chat open and working in that browser
- [ ] Notifications, badges, and personal tabs closed or hidden before you share a screen
- [ ] Presentation profile or clean browser window with no confidential content visible

**Decisions made in advance**
- [ ] Foundry demo choice: live project, or the no-access walkthrough
- [ ] Group size and how you will form groups
- [ ] Who monitors chat or supports the room
- [ ] What you will cut first if you are running behind

## Virtual delivery only

- [ ] Meeting link tested, with a backup link in the invite
- [ ] Breakout rooms pre-created, sized 3-4
- [ ] Co-facilitator assigned to chat monitoring and time warnings
- [ ] Screen sharing tested at 150 percent browser zoom
- [ ] Recording decision made and announced at the start, if applicable
- [ ] Poll created for the knowledge check at minutes 82-87, or chat fallback agreed
- [ ] Headset and a wired or reliable connection
- [ ] Return-from-break clock time ready to post in chat and on the slide
- [ ] Plan for silent rooms: named reporters, one-line checkpoints

## In-person delivery only

- [ ] Room booked with tables of 4-6, not rows
- [ ] Projector or large screen tested with your laptop and the actual browser zoom
- [ ] Guest or corporate network details on screen at the start
- [ ] Power strips for laptops
- [ ] Whiteboard or flip chart plus markers, for the parking lot
- [ ] Sticky notes for checkpoints, one pad per table
- [ ] Printed copies for fallback: the improved prompt reference, the evaluation rubric, the PR
      checklist, and the reference pull request
- [ ] Refreshments and break location confirmed
- [ ] Clock or timer visible from every seat
- [ ] Accessibility: readable font size on screen, step-free access, seating confirmed with
      anyone who told you they need it

## Immediately before start

- [ ] Open the room or meeting 10 minutes early
- [ ] Repository and workbook links posted and on screen
- [ ] Timer started at minute 0, not minute 3
- [ ] Say the synthetic-data-only rule before any chat surface is used

## After each delivery

- [ ] Note where you ran over or under, per segment, in your own copy of the guide
- [ ] Collect questions you could not answer and add them to
      [train-the-trainer.md](train-the-trainer.md) FAQs
- [ ] Note any exercise that consistently confused people and open an issue
- [ ] If you changed content, run `python validate.py` before pushing
- [ ] Share participant commitments with whoever owns follow-up
